# Level 1 – Task 1: Exploratory Data Analysis on Retail Sales Data

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to understand customer purchasing behavior, sales patterns and product category performance.

The objective is to explore the dataset, identify meaningful patterns and extract useful business insights through data analysis and visualization.

## Objective

- Analyze retail sales transactions.
- Understand monthly and quarterly sales trends.
- Examine customer demographics and purchasing behavior.
- Identify popular product categories.
- Analyze revenue distribution across different categories and genders.
- Explore relationships between numerical variables.
- Derive meaningful business insights from the data.

## Dataset Information

**Dataset:** `retail_sales_dataset.csv`

The dataset contains:
- Total Records: 1,000
- Total Columns: 9
- Missing Values: 0

### Dataset Attributes

| Column | Description |
|---|---|
| Transaction ID | Unique transaction identifier |
| Date | Transaction date |
| Customer ID | Customer identifier |
| Gender | Customer gender |
| Age | Customer age |
| Product Category | Purchased product category |
| Quantity | Number of items purchased |
| Price per Unit | Price of each unit |
| Total Amount | Total transaction amount |

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

### 1. Data Loading and Inspection
Loaded the retail sales dataset and examined its structure, dimensions, data types and statistical information.

### 2. Data Cleaning and Preprocessing
- Checked for missing values.
- Examined data types.
- Converted transaction dates into appropriate date format.
- Prepared data for further analysis.

### 3. Monthly Sales Analysis
Analyzed sales revenue across different months to understand monthly purchasing patterns.

### 4. Quarterly Sales Analysis
Examined quarterly revenue distribution to identify seasonal sales patterns.

### 5. Customer Age Group Analysis
Grouped customers into different age categories and analyzed their distribution.

### 6. Gender-Based Analysis
Examined customer distribution and purchasing behavior based on gender.

### 7. Product Category Analysis
Analyzed product categories based on:
- Quantity sold.
- Total revenue generated.

### 8. Revenue Analysis by Gender
Compared the total revenue contributed by different customer gender groups.

### 9. Correlation Analysis
Used a correlation heatmap to explore relationships between numerical variables such as age, quantity, price per unit and total amount.

## Visualizations

The analysis uses visualizations to understand:
- Monthly and quarterly sales trends.
- Customer age distribution.
- Gender distribution.
- Product category performance.
- Revenue comparisons.
- Correlations between numerical variables.

## Key Learning Outcomes

- Learned how to perform EDA using Pandas.
- Gained experience in data cleaning and preprocessing.
- Practiced grouping and aggregating data.
- Developed data visualizations using Matplotlib and Seaborn.
- Improved the ability to interpret customer and sales data.

## Conclusion

This project provided practical experience in analyzing retail transaction data and understanding customer purchasing patterns.

The analysis demonstrates how exploratory data analysis and visualization can help identify sales trends, customer characteristics and product category performance.

**Note:** The dataset provides product categories rather than individual product names; therefore, product-level analysis was not performed.
