# Oasis Infobyte Internship – Data Analytics

## About This Repository

This repository contains my completed projects as part of the **Oasis Infobyte Data Analytics Internship**.

The internship provided an opportunity to apply data analytics, data preprocessing, exploratory data analysis, data visualization, machine learning and predictive modeling techniques to real-world datasets.

I have successfully completed four tasks across Level 1 and Level 2.

## Internship Details

- **Organization:** Oasis Infobyte
- **Domain:** Data Analytics
- **Track:** Data Analytics
- **Completed Tasks:** 4
- **Levels:** Level 1 and Level 2
- **Programming Language:** Python
- **Development Environment:** Jupyter Notebook

## Completed Tasks

### Level 1

| Task | Project Title | Description |
|---|---|---|
| Task 1 | EDA on Retail Sales Data | Analyzed customer purchasing patterns, sales trends, product categories and revenue distribution. |
| Task 2 | Customer Segmentation Analysis | Segmented customers using purchasing behavior and RFM analysis. |

### Level 2

| Task | Project Title | Description |
|---|---|---|
| Task 1 | House Price Prediction | Developed a Linear Regression model to predict house prices using property features. |
| Task 2 | Wine Quality Prediction | Built and evaluated machine learning classification models to predict wine quality. |
